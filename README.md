# Civilization 5, Vox Populi - Russian translation

---

### Перевод мода Vox Populi для Civilization 5 на русский язык.

Версия релиза напрямую соответствует версии Vox Populi.

Сначала переводил файлы локализации пачками с помощью ChatGPT. Потом правил отдельные термины на своё усмотрение. И далее по ходу игры поправлял места, где текст некрасиво смотрится ввиду чуть большего объёма русского текста по сравнению с английским. Часто буквы выходили за края форм, границы кнопок или налазили друг на друга. Поэтому где-то пришлось подрезать. Где осталось некрасиво - значит либо я на это не обратил внимание, либо решил оставить как есть (напр. список идеологических догматов 1 уровня - очень сложно там как-то сократить текст без значительной потери смысла).

## Установка

1. Скачайте архив перевода отсюда [tags](https://github.com/alekseenkoSergey/civ5_voxpopuli_ru_translation/tags).
2. Найдите папку с настройками игры, скорее всего это С:\Users\имя_пользователя\Documents\My Games\Sid Meier's Civilization 5
3. Вставьте файлы из архива туда. Удостоверьтесь что в вашей папке MODS появились папки с переводом рядом с папками основного мода.
4. После запуска игры, выбрав Модификации, активируйте моды с переводом.
